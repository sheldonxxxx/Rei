Dev Notes #node

Graceful shutdown in Node.js

When a container orchestrator stops your service it sends SIGTERM and waits for a grace period before SIGKILL. Use that window to stop taking new requests and finish the ones in flight.

Stop accepting connections

const server = http.createServer(app);
server.listen(8080);

process.on("SIGTERM", () => {
  server.close(() => process.exit(0));
  setTimeout(() => process.exit(1), 25_000).unref();
});

The 25 second fallback timer stays under the default 30 second grace period, so the process exits on its own terms.

Drain keep-alive sockets

Since Node 18.2, server.closeIdleConnections() closes idle keep-alive sockets so that server.close() does not wait for them.

process.on("SIGTERM", () => {
  server.close();
  server.closeIdleConnections();
});

Health checks

Flip your readiness probe to failing as soon as SIGTERM arrives, so the load balancer stops routing new traffic before the server closes.
