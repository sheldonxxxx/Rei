Configuring webhooks

Larkspur sends an HTTP POST to your endpoint whenever an event you subscribe to happens. This guide covers creating an endpoint, verifying signatures, and handling retries.

Create an endpoint

Endpoints are created per project. Each project can have up to 16 webhook endpoints.

larkspur webhooks create --url https://example.com/hooks --events order.created,order.paid

Verify signatures

Every delivery carries a Larkspur-Signature header. It is an HMAC-SHA256 of the raw request body, keyed with the endpoint's signing secret.

import { createHmac, timingSafeEqual } from "node:crypto";

export function verify(body: string, header: string, secret: string): boolean {
  const expected = createHmac("sha256", secret).update(body).digest("hex");
  return timingSafeEqual(Buffer.from(expected), Buffer.from(header));
}

Warning

Compute the signature over the raw body bytes. Parsing and re-serialising JSON changes whitespace and breaks the check.

Retries

A delivery that does not get a 2xx response within 10 seconds is retried with exponential backoff for up to 3 days. After the final attempt the event is marked failed and shown in the dashboard.

Ordering

Deliveries are not guaranteed to arrive in order. Use the event's created_at timestamp to discard stale updates.
